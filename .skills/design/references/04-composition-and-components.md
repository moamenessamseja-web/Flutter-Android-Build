# Composition and Components

Work from large to small: screen regions → content groups → repeated patterns → component anatomy → typography/icons/micro-spacing.

For each reusable component specify purpose, anatomy, variants, states, interaction, responsive behavior, accessibility semantics, and data/actions. Reuse components when they represent the same concept/behavior, not merely because two rectangles look alike.

Use a card when information is a self-contained unit with a meaningful boundary/action. Use a row when items are repeated and comparable. Use section headers to group content; do not wrap every section in a card by default.

Specify minimum width, wrapping/truncation, row-to-column behavior, long Arabic labels, large text, scroll ownership, and safe areas. Avoid fixed heights for content that can grow with localization or font scaling.
