# Visual Hierarchy and Visual Language

Create an attention order using position, grouping, size, weight, contrast, whitespace, alignment, repetition, and rhythm. Define primary focus, secondary information, supporting metadata, actions, and deferred details. If everything is emphasized, nothing is.

Density is contextual: low density is not automatically better, high density is not automatically efficient. Remove repetition/decor before useful information. Use rows for compact comparable data and cards for meaningful grouped units; do not card-wrap every metric.

Define 3–5 visual attributes and explain their effect on palette, type, shape, iconography, imagery, charts, and motion. Separate brand/action, category, semantic status, and surface colors. Never use category color to imply status. Pair status color with icon and text; verify contrast.

Use bundled/licensed fonts that render required scripts. Establish type roles. Isolate mixed-direction runs. Units must be domain-correct; kW and kWh are not interchangeable. Reference products are pattern evidence, not proof of market validation or permission to copy a whole screen.
